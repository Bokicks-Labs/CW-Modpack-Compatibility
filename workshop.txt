title=Chaosworld B42 Modpack Compatibility
description=[h1]Chaosworld B42 Modpack Compatibility[/h1]
description=
description=Targeted compatibility fixes for a heavily modded Project Zomboid Build 42 multiplayer world. [b]The core supports Build 42.20+; the optional Viewpoint patch requires 42.21+.[/b] Install each original mod you use; CW does not replace upstream mods. Runtime hooks are conditional on their target mods.
description=
description=[h2]Load order and multiplayer[/h2]
description=Place [b]CWModpackCompatibility after the mods it patches[/b], near the end of the Mods list.
description=
description=For Lifestyle:
description=[olist]
description=[*]LifestyleHobbies
description=[*]LifestyleHobbiesFix (only if installed)
description=[*]CWModpackCompatibility
description=[/olist]
description=Bandits2, BanditsWeekOne, DynamicTradingCommon, DynamicTradingV2, ETO_B and other patched mods should also load before the CW core. Enable optional submods separately. CWAudioMixer and CWModOptionsSearch should load after the core; CWViewpointPatch should load after Viewpoint.
description=
description=For multiplayer, keep server/client versions and mod lists aligned and restart after changing order or ownership settings. Back up saves before removing mods.
description=
description=[h2]Core compatibility fixes[/h2]
description=[list]
description=[*][b]Lifestyle: Hobbies:[/b] Hidden-skill view (Yoga, Inventing, Ping Pong, Pool and Arcade), Beyond Ten progress integration, animation-regression mirror, diagnostics and automatic feature ownership. Nature's Call can own bathroom needs, Brush Your Damn Teeth can own dental hygiene, and CW can disable Lifestyle's overlapping personal hygiene meter/moodles by default. Lifestyle cleaning actions, Cleaning skill, other grooming, hobbies and animations remain available.
description=[*][b]Nature's Call:[/b] Fresh-character clock-jump guard and multiplayer clothing-wash recovery without discarding real need progression.
description=[*][b]Brush Your Damn Teeth:[/b] Suppress Lifestyle's duplicate brushing actions while keeping its unrelated actions.
description=[*][b]Moodles in Lua:[/b] Keep the duplicate vanilla Moodle UI off screen even when Build 42 repositions it.
description=[*][b]CleanUI + Equipment UI:[/b] Guard temporary missing inventory context menus to prevent tooltip exceptions.
description=[*][b]Every Texture Optimized (ETO_B):[/b] Narrow vanilla-safe rain-texture override for a world-loading crash.
description=[*][b]Bandits and Week One:[/b] Safe companion-loot targeting, optional player-hit reactions, and guarded Week One multiplayer variant/removal/chat boundaries.
description=[*][b]Dynamic Trading:[/b] NPC attachment, networking and old wardrobe-ID guards plus contacts UI compatibility.
description=[*][b]Other fixes:[/b] Gael Gun Store timed-action safety; Take A Bath And Shower menus; item recovery; Fast Forward / Exact Minute Clock layout; Quartermaster categories; moved Build 42 UI modules; DAMN/KI5 attachments and text repairs.
description=[*][b]Casualties Undead (optional):[/b] Adds top-level Full health shortcuts to the Health panel's body-part menu only while the game's Cheat option is enabled; no normal treatment changes.
description=[/list]
description=
description=[h2]Optional submods[/h2]
description=[list]
description=[*][b]CW Audio Mixer (0.2.0):[/b] Client-only group and individual sound sliders. Find its group controls under Options > Audio > CW Audio Mixer; Advanced sound mixer handles individual sounds and assignments. Categories include UI, death music, TV, radio, music, ambience, vehicles and combat. Settings are local. The title-screen video audio cannot reliably be controlled by this Lua mixer; vanilla rain is part of a shared ambience event, not an isolated rain slider.
description=[*][b]CW Mod Options Search (0.1.2):[/b] Client-only search inside Options > Mods for registered mod settings, labels and tooltips. Select a result to jump to an available option; search never edits setting values.
description=[*][b]CW Viewpoint Patch (0.2.0, experimental):[/b] Client-only Build 42.21+ patch for wider Viewpoint interaction labels, Project A-Life NPC selection and a guarded right-click fallback. Requires [b]Viewpoint and ZombieBuddy[/b]. Enable separately after Viewpoint. Configure label width under Options > Mods > CW Viewpoint Patch and restart. The included Java JAR requires explicit approval via ZombieBuddy. Test in a disposable save; NPC outlines and world interactions are not fully verified.
description=[/list]
description=
description=[h2]Project Viewpoint and ZombieBuddy[/h2]
description=Subscribe to the [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3619862853]official ZombieBuddy Workshop item[/url] and follow its current installation instructions before using Viewpoint. [b]The old CW ZombieBuddy setup launcher and bundled compatibility JAR were removed.[/b] Installing CW never downloads, executes, or repairs ZombieBuddy. On Windows, do not overwrite an already-working native DLL merely for cleanup if its current setup differs from upstream. ZombieBuddy and Viewpoint are third-party projects, not Chaosworld releases.
description=
description=[h2]Configuration and testing[/h2]
description=Bandits hit reactions and Lifestyle feature ownership are configured under Sandbox Options. Each Lifestyle ownership rule can be disabled independently; restart for changes. The optional Lifestyle skill view is under Mod Options. Existing saves may contain settings or obsolete Viewpoint add-ons: back up saves and validate any migration separately.
description=
description=Compatibility behavior was previously tested for several fixes, and the repo has focused regression scripts, but this 1.2.0 candidate has [b]not yet passed a new end-to-end game or multiplayer test[/b]. Please report reproducible errors with the current game/mod version and relevant console log.
