description=CURRENT COMPATIBILITY FEATURES
description=- Lifestyle: optional hidden-skill view for Yoga, Inventing, Ping Pong, Pool, and Arcade; Beyond Ten progress bridging; and focused recovery/diagnostic controls. CW now relies on Lifestyle's current animation and yoga files and no longer redistributes them.
description=- Bandits: safe companion container-loot targeting and configurable client hit reactions after confirmed firearm or melee damage.
description=- Week One: guarded multiplayer variant, population-removal, inhabitant-spawn, and pre-player chat boundaries. These hooks activate only when BanditsWeekOne is installed.
description=- Dynamic Trading: NPC attachment guards, pre-network player-anchor guards, obsolete wardrobe ID repair, and contacts UI compatibility.
description=- Timed actions and washing: safe Gael Gun Store weapon-part completion, Nature's Call multiplayer clothing-wash recovery, Take A Bath And Shower menu compatibility, and generic alternate-form item recovery.
description=- UI and data: Fast Forward plus Exact Minute Clock positioning, Quartermaster runtime categories, moved Build 42 UI modules, DAMN/KI5 semi-attachment compatibility, and malformed English/sandbox text repairs.
description=
description=CONFIGURATION
description=Bandits hit reactions can be enabled and tuned in Sandbox Options. The Lifestyle compatibility skill view can be toggled in Mod Options. CW 1.1.11 does not add a save migration, but backing up saves before mod-list changes is always recommended.
