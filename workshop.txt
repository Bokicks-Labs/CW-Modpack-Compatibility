description=[h1]Chaosworld B42 Modpack Compatibility[/h1]
description=
description=Targeted, conditional compatibility fixes maintained for the Chaosworld Project Zomboid 42.20 modpack. Install the original mods for the features you use; this item does not replace them. Each runtime patch stays dormant when its supported mod is absent.
description=
description=[h2]Important load order[/h2]
description=
description=Place [b]CW Modpack Compatibility after the mods it patches[/b], near the end of the Mods list.
description=
description=Required Lifestyle order:
description=[olist]
description=[*]LifestyleHobbies
description=[*]LifestyleHobbiesFix — optional; include it only when installed
description=[*]CWModpackCompatibility
description=[/olist]
description=
description=Bandits2, BanditsWeekOne, DynamicTradingCommon, DynamicTradingV2, ETO_B, and other supported mods must also appear before CWModpackCompatibility.
description=
description=CW Audio Mixer is optional and, when enabled, must appear after CWModpackCompatibility.
description=CW Mod Options Search is optional and, when enabled, must also appear after CWModpackCompatibility.
description=
description=For multiplayer, clients and the server should use the same mod list, order, and CW version. Fully restart the client and server after changing the order.
description=

description=[h2]Optional Windows setup for Project Viewpoint[/h2]
description=
description=The CW download includes an inert [b]ZombieBuddy-Setup[/b] folder for the private Chaosworld friend group. It contains Antikristianos's temporary Build 42.21 compatibility JAR, licenses, provenance, and a guarded PowerShell installer. If the base agent is missing, the helper can download Zed's official ZombieBuddy Windows installer v4.2 from GitHub on explicit request. Enabling CW never runs these files; a player must deliberately launch the setup tool from the Workshop folder.
description=
description=The helper verifies pinned SHA-256 hashes, refuses to patch a running PZ installation, backs up the existing JAR, and supports status and restore operations. It does not alter saves, subscriptions, Java-mod approvals, Steam launch options, execution policy, or unrelated mods. The official installer is not included because the PZ Workshop uploader forbids EXE files; a verified temporary download is deleted after use. The upstream installer is not Authenticode-signed. Java mods have unrestricted process access, so approve only expected JARs.
description=
description=Project Viewpoint, ZombieBuddy, and the temporary fix remain third-party projects and are not authored or endorsed by Chaosworld. See the included third-party notices and licenses.

description=[h2]Current compatibility features[/h2]
description=
description=[list]
description=[*][b]Lifestyle: Hobbies:[/b] Optional hidden-skill view for Yoga, Inventing, Ping Pong, Pool, and Arcade; Beyond Ten progress bridging; focused recovery and diagnostic controls; automatic feature ownership; and a 400-file animation mirror restored to prevent missing-animation regressions. When the corresponding owner mods are active, Nature's Call handles bathroom needs and Brush Your Damn Teeth handles dental hygiene by default. Lifestyle continues to own its other hygiene, grooming, cleaning, hobby, yoga, and animation features.
description=[*][b]Nature's Call:[/b] Owns bladder and bowel needs when used with Lifestyle by default. Also prevents a fresh character's startup clock transition from being mistaken for hours of needs progression, retains multiplayer clothing-wash recovery, and leaves legitimate Nature's Call needs untouched.
description=[*][b]Brush Your Damn Teeth:[/b] Owns dental hygiene when used with Lifestyle by default. Lifestyle's duplicate brushing actions are suppressed without removing its other mirror, cabinet, grooming, or hygiene actions.
description=[*][b]CleanUI + Equipment UI:[/b] Guards transient missing inventory context menus during UI initialization and teardown, preventing the repeated tooltip exception and console flood.
description=[*][b]Every Texture Optimized — Well Balanced:[/b] Supplies a narrowly scoped vanilla-safe rain texture after ETO_B to prevent a null weather-particle texture from crashing an existing save during world loading.
description=[*][b]Bandits NPC:[/b] Safe companion container-loot targeting and configurable client hit reactions after confirmed firearm or melee damage.
description=[*][b]Week One NPC:[/b] Guarded multiplayer variant, population-removal, inhabitant-spawn, and pre-player chat boundaries. These hooks activate only when BanditsWeekOne is installed.
description=[*][b]Dynamic Trading:[/b] NPC attachment guards, pre-network player-anchor guards, obsolete wardrobe ID repair, and contacts UI compatibility.
description=[*][b]Timed actions and washing:[/b] Safe Gael Gun Store weapon-part completion, Take A Bath And Shower menu compatibility, and generic alternate-form item recovery.
description=[*][b]UI and data:[/b] Fast Forward plus Exact Minute Clock positioning, Quartermaster runtime categories, moved Build 42 UI modules, DAMN/KI5 semi-attachment compatibility, and malformed English and sandbox text repairs.
description=[/list]

description=[h2]Configuration[/h2]
description=
description=[list]
description=[*]Bandits hit reactions can be enabled and tuned in Sandbox Options.
description=[*]Lifestyle ownership defaults require no setup and can be overridden independently under Chaosworld Compatibility - Lifestyle Ownership in Sandbox Options. Restart after changing them. Removing an owner mod automatically returns that feature to Lifestyle; CW also restores Lifestyle's default bladder multiplier if an older preset left it at zero, unless that fallback is disabled.
description=[*]The Lifestyle compatibility skill view can be toggled in Mod Options.
description=[*][b]CW Audio Mixer (optional submod):[/b] Enable [i]CW Audio Mixer[/i] separately after CW Modpack Compatibility. It is client-only and discovers loaded game/mod sounds for local group and per-sound volume controls. Open it in Mod Options or from the world right-click menu. Vanilla rain shares PZ's World Ambience event, so its control also changes other weather ambience.
description=[*][b]CW Mod Options Search (optional submod):[/b] Enable it separately after CW Modpack Compatibility. It adds a client-only search launcher to the first section of the Build 42 Mod Options page and jumps to matching registered mod settings without changing their values.
description=[/list]
description=
description=CW 1.1.14 adds the optional, user-launched Windows setup bundle. It does not run during gameplay or change save data. Back up important saves before changing mod lists.
