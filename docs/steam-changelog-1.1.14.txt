[h2]Changed[/h2]
[list]

[/list]

[h2]Safety and behavior[/h2]
[list]
[*][b]Nothing runs automatically.[/b] Enabling CW Modpack Compatibility does not execute the setup helper or load Project Viewpoint.
[*]The helper refuses to replace the ZombieBuddy JAR while the targeted Project Zomboid installation is running.
[*]The existing JAR is backed up before replacement, and both the bundled patch and final installed file are verified by SHA-256.
[*]If the base ZombieBuddy agent is missing, the helper can explicitly download Zed's pinned official v4.2 installer from GitHub, verify it, run it interactively, and delete the temporary download afterward. The EXE is not stored in the Workshop item because Project Zomboid forbids executable uploads.
[*]The helper does not edit saves, Workshop subscriptions, Java-mod approvals, Steam launch options, execution policy, or unrelated mods.
[/list]

[h2]Important[/h2]
[list]
[*]Each Windows player who wants Project Viewpoint must deliberately run the included setup helper while Project Zomboid is closed.
[*]Players must still approve the expected Project Viewpoint JAR when ZombieBuddy prompts. Do not approve unexpected Java mods.
[*]The upstream ZombieBuddy installer is not Authenticode-signed. The setup documentation includes the pinned release and SHA-256 so users can make their own trust decision.
[/list]
