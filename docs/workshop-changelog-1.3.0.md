# Version 1.3.0

Adds the optional CW Modded UI Layout 0.1.0 submod for Casualties Undead.

- Expands the Health Vitals report and arranges debug controls in measured, scrollable columns.
- Adds space to treatment-minigame headers, Vitals readings, SITE and injury tags, event timestamps, and footer controls.
- Leaves Casualties Undead's treatment and debug handlers in place. The submod is client only and does not require the CW core.

Enable `CWModdedUILayout` after `CasualtiesUndead`. The layout was refined from in-game 2560x1440 screenshots of the Health panel, debug window, and dressing and tourniquet minigames. Other resolutions, languages, and minigames have not all been checked in game.
